# Жайлуу Үй

Мебельный каталог для Нооката на кыргызском и русском. По умолчанию открыт кыргызский интерфейс. Корзина и язык сохраняются в хранилище браузера.

## Открыть локально

Распакуйте проект и откройте `index.html` в браузере. Для проверки под адресом с подпапкой можно запустить статический HTTP-сервер из родительской папки и открыть `/furniture-demo/`. Сборка и внешние зависимости не нужны.

## Настроить под магазин

- **Название и контакты.** В `shop.js` поменяйте `name`. В `whatsapp` можно указать публичный номер магазина в международном формате, с кодом страны. Пустая строка скрывает кнопку. При заполненном номере кнопка открывает WhatsApp с готовым сообщением для ручной отправки. Номер из конфигурации виден в исходниках публичного сайта.
- **Товары и цены.** В массиве `products` файла `shop.js` укажите уникальный `id`, категорию `sofas`, `beds`, `wardrobes` или `tables`, цену в целых сомах в поле `price` и размеры в сантиметрах в поле `size`. В массивах `ky` и `ru` по порядку идут название, материал и описание. Сохраняйте `id` при правках действующего товара, чтобы он оставался в сохранённых корзинах.
- **Фотографии.** Положите файлы в `assets/` и впишите имена в `images` у нужного товара. Первый снимок используется в каталоге, второй открывается как крупный план. Для заставки замените `assets/hero.jpg`. Фотографии созданы с помощью OpenAI ImageGen, крупные планы кадрированы из снимков товаров.
- **Тексты и оформление.** Словари интерфейса находятся в `app.js`, цвета и размеры в `styles.css`. Метаданные страницы и начальный текст без JavaScript находятся в `index.html`.

## Цены

Цены указаны в сомах по предложениям сопоставимой мебели в Кыргызстане, просмотренным 8 ноября 2026 года. Модели и фотографии в этом каталоге созданы для «Жайлуу Үй». Перед приёмом заказов укажите цены и характеристики ваших товаров. [Азбука Дома](https://azbukadoma.kg/) · [LINA](https://lina.kg/catalog/) · [Eco Service](https://eco-service.kg/mebel-na-zakaz/)

## Опубликовать через GitHub Pages

Загрузите файлы проекта в корень ветки `main` отдельного публичного репозитория, включая папку `assets/` и файл `.nojekyll`. В GitHub откройте **Settings → Pages**. В **Source** выберите **Deploy from a branch**, затем **main**, **/(root)** и **Save**. После завершения публикации GitHub покажет адрес сайта. Ссылки на файлы относительные, поэтому каталог работает и в подпапке репозитория.
